# 从baseline到最终V3

1. WOUAF生成器训练固定3000steps，记录NGC93.42%、TRAIN TYPE VAL93.40%、CLIPScore.37329，保存portable snapshot。之后不更新生成器与mapping。
2. CPU初期研究BCH31不同容量、parity、Correct/Reject/False Attribution；这是历史探索，最终流程不再运行synthetic ECC。
3. 真实图像导出GT32bits与预测32bits/logits，统计Hamming、BER、P(E=k)、bit频率/相关性；基于真实码字评估用户恢复。5000指每组评估图数。
4. 实际JPEG暴露420色度采样脆弱性；区分444/420与真正编码，排除仅重命名/不真实压缩等流程问题。
5. 修复/复核预处理与软件恢复，固定软件栈。历史生成器deterministic=False与提取True必须分别保留；恢复12张baseline控制逐像素匹配。
6. 早期+200/+300提取器改进后，加入自然图和同源无水印负样本、presence双头与配对训练；V1训练2400步。
7. V2从V1追加2400步，选择extra800，加入完整BCH码字CE和更多真实420，420提高但PNG/444回落。
8. 额外1600步的单模型V3与补充权重融合尝试未通过严格保留，保存失败和step0回退记录。
9. 最终V3组合原V1/V2，按真实文件头路由，一次前向/图，固定门槛；旧4096源图队列验证格式保留，但明确其是已观察回归。
10. 冻结V3后，生成1024个新prompt/seed/latent单元与新自然照片，形成4096源图、12288视图；无训练/调门槛/结果筛图。k11JPEG420+2.73pp、k16+4.00pp，两者CI为正，PNG/444逐样本相同；有限样本零观察误归属。
11. 用户选择最终V3，整理默认预训练项目、独立训练、V1/V2对照、完整软件/流程/结果/复现材料，另存Drive。本次没有追加训练或推送GitHub。
